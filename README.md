One page for one day: a newspaper front page drawn with Pillow that sums up Monday 23 November
2026 — the Ukrainian drone attack on a Russian corvette in Libya, COP31 closing without a deal,
three more ships struck off Iran, a factory fire in Indonesia and the US House result — each
story carried by its own pictogram, the date set at 90 px so it is the first thing read.

## Run it

```sh
python3 news/build_image.py --out news/entry.png   # redraws the image
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
